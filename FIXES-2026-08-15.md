# 010 — WireGuard-фикс + watchdog бота + рассылка (15.08.2026)

> Три операционных улучшения, применённых 15.08.2026. Код бота (`bot.py`) не менялся —
> это серверная инфраструктура (конфиги, скрипты, юнит).

## 1. WireGuard — починен (мёртв 2 месяца)

**Проблема:** кнопка «🔒 WireGuard» в меню была, но WG-подписок 0. `wg-quick@wg0`
в статусе `failed` с 16.06.2026. Причина — в `/etc/wireguard/wg0.conf` лежал peer с
битым PublicKey (43 символа без завершающего `=`, WireGuard требует ровно 44).

```bash
sudo wg-quick up wg0 2>&1
# → "Key is not the correct length or format: `9YMnaIQeKQGslpWcWmpucRlT88DzoTf9XbxpXJDuzWU'"
```

**Фикс:** удалить битый peer-блок, поднять через systemd, сверить pubkey с `.env`:

```bash
sudo cp /etc/wireguard/wg0.conf /etc/wireguard/wg0.conf.bak_$(date +%Y%m%d)
sudo python3 -c "
conf = open('/etc/wireguard/wg0.conf').read()
if '[Peer]' in conf:
    conf = conf.split('[Peer]')[0].rstrip() + '\n'
open('/etc/wireguard/wg0.conf','w').write(conf)
"
sudo systemctl reset-failed wg-quick@wg0
sudo systemctl start wg-quick@wg0
# Проверка консистентности pubkey (иначе бот выдаст неверный WG-конфиг)
REAL=$(sudo wg show wg0 public-key)
ENV=$(sudo grep '^WG_SERVER_PUBKEY=' /opt/vpn-seller-bot/.env | cut -d= -f2-)
[ "$REAL" = "$ENV" ] && echo "✅ совпадает" || echo "❌ РАСХОДИТСЯ"
```

**Нюанс:** WG слушает `ListenPort=443` (UDP) — конфликта с MTProto (443/TCP) нет.

## 2. Двойной systemd юнит — устранён

Существовали ДВА юнита: system-level (`/etc/systemd/system/`, `User=vpn-bot` —
правильный) и user-level (`~/.config/systemd/user/`, от `openclaw` — мусорный
дубликат). User-level падал в цикле (`restart counter` 1696): держал чужой
`bot.lock` и не имел прав на `data/` (принадлежит `vpn-bot`).

**Фикс:** `systemctl --user stop/disable` + удалить файл дубликата.

**Урок:** единственный правильный юнит — system-level. Preflight может ложно
показывать «inactive» (смотрит user-level) — проверять `sudo systemctl status`.

## 3. Watchdog бота — `vpn-core/vpn-bot-watch.py`

`vpn-watch.py` следит только за xray. Новый watchdog следит за **ботом** —
проверяет polling-лог на `Unauthorized`/`TelegramConflictError`/`Failed to fetch`
(aiogram ретраит `Unauthorized` бесконечно, `systemctl` при этом показывает
active — ложная живость).

Cron (root, каждый час):
```
0 * * * * python3 /home/openclaw/.hermes/scripts/vpn-bot-watch.py >> /var/log/vpn-bot-watch.log 2>&1
```
Алерт в TG админу при смерти, с cooldown 1 час. Стейт — `~/.hermes/logs/vpn-bot-watch.state`.

## 4. Рассылка по базе — `scripts/vpn-broadcast.py`

Разовая рассылка всем пользователям (сообщить о Stars-оплате и триале). Дедупликация
через стейт-файл `~/.hermes/logs/vpn-broadcast.sent` (безопасный перезапуск).
